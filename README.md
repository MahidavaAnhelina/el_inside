# El_Inside

Сайт мастерской на **Next.js 16 / React 19 / TypeScript**, подготовленный для **Vercel + Telegram + Turnstile + Upstash Redis**. Утверждённый дизайн, локальные шрифты и логотип сохранены. Репозиторий самостоятельный; `origin` подключён к `MahidavaAnhelina/el_inside`.

## Что работает

- `/pl/`, `/ru/` и `/en/`: отдельные адреса и серверный HTML на каждом языке; `/` перенаправляет на `/pl/`. Других страниц пока нет.
- Галерея с фильтрами, выбор изделия, заявка на новое изделие или изменения существующего.
- До 5 файлов JPG, PNG, WEBP, PDF, **до 3 МБ суммарно**, плюс ссылки на референсы.
- `POST /api/orders/`: серверная проверка полей и вложений, заявка и файлы в Telegram владелицы, email клиента внутри заявки.
- Состояния отправки и ошибок; данные формы сохраняются при ошибке. Turnstile, общие лимиты 5 попыток/IP/минуту, 20 отправок/час и 50/сутки, пауза 20 секунд между отправками; дедупликация содержимого на 24 часа.
- Адаптивный дизайн и анимации с учётом `prefers-reduced-motion`.
- Локализованные metadata, canonical, hreflang, sitemap и robots.

Без env сайт открывается, но отправка возвращает сообщение о недоступности — ложного подтверждения отправки нет. Это запрос на обсуждение, не автоматическое оформление покупки: оплаты, базы заказов и личного кабинета нет. Redis хранит только технические счётчики и состояния доставки.

## Быстрый запуск

Нужен Node.js **24 LTS**. Если используете nvm:

```sh
nvm use
npm ci
test -f .env.local || cp .env.example .env.local
npm run dev
```

Откройте [польскую](http://localhost:3000/pl/), [русскую](http://localhost:3000/ru/) или [английскую](http://localhost:3000/en/) версию. Для проверки production-режима: `npm run build`, затем `npm start`.

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run format:check
```

Тесты подменяют внешние сервисы: настоящих сообщений и писем не отправляют. Они проверяют валидацию, вложения, Turnstile, отказ при сбоях защиты, дедупликацию, Telegram, альтернативную доставку Resend и переводы.

Проверка самих Lua-счётчиков без внешнего Redis: установите `fakeredis[lua]` в отдельное Python-окружение и выполните `python tests/check_limits.py`. Она проверяет параллельные резервирования, границы окон и общий лимит; production-ключи не используются.

## Перед публикацией

Пройдите production-гайд, включите отправку через `ORDERS_ENABLED=true` и проверьте одну настоящую заявку в Telegram. Включите ограничение частоты запросов в Vercel Firewall: honeypot и проверка Origin отсеивают часть нежелательных запросов, но не заменяют защиту от ботов. Уточните информационный текст о данных клиентов для реальной работы мастерской — текущий блок описывает передачу заявки, но не является полной политикой обработки данных.

**Бесплатность:** Vercel Hobby предназначен для личного некоммерческого использования. Для сайта, принимающего платные заказы, не рассчитывайте на Hobby: выберите тариф, разрешающий коммерческое использование. Свой домен для Telegram-варианта не требуется. У Turnstile и Upstash есть бесплатные планы с действующими условиями и квотами. Источники и подробности — в гайдах.

Альтернативная доставка писем: `ORDER_DELIVERY=resend` и [гайд Resend](docs/resend.md). Для неё нужен подтверждённый домен отправителя; все проверки защиты также обязательны.
