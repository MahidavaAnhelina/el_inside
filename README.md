# El_Inside

Сайт мастерской на **Next.js 16 / React 19 / TypeScript**, подготовленный для **Vercel + Resend**. Утверждённый дизайн, локальные шрифты и логотип сохранены. Репозиторий самостоятельный; `origin` подключён к `MahidavaAnhelina/el_inside`.

## Что работает

- `/pl/` и `/en/`: отдельные адреса и серверный HTML на каждом языке; `/` перенаправляет на `/pl/`. Других страниц пока нет.
- Галерея с фильтрами, выбор изделия, заявка на новое изделие или изменения существующего.
- До 5 файлов JPG, PNG, WEBP, PDF, **до 3 МБ суммарно**, плюс ссылки на референсы.
- `POST /api/orders/`: серверная проверка полей и вложений, письмо владелице через Resend, email клиента в Reply-To.
- Состояния отправки и ошибок; данные формы сохраняются при ошибке. Ключ повторной отправки защищает от дублей в течение окна идемпотентности Resend.
- Адаптивный дизайн и анимации с учётом `prefers-reduced-motion`.
- Локализованные metadata, canonical, hreflang, sitemap и robots.

Без env сайт открывается, но отправка возвращает сообщение о недоступности — ложного подтверждения отправки нет. Это запрос на обсуждение, не автоматическое оформление покупки: оплаты, базы заказов и личного кабинета нет.

## Быстрый запуск

Нужен Node.js **24 LTS**. Если используете nvm:

```sh
nvm use
npm ci
cp .env.example .env.local
npm run dev
```

Откройте [польскую](http://localhost:3000/pl/) или [английскую](http://localhost:3000/en/) версию. Для проверки production-режима: `npm run build`, затем `npm start`.

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npm run build
npm run format:check
```

Тесты подменяют почтовый транспорт, настоящие письма не отправляют. Они проверяют данные заявки, вложения, лимит тела запроса, ошибки Resend, повторные запросы и полноту переводов.

## Перед публикацией

Настройте адрес отправителя, адрес получателя и API-ключ по гайдам. Проверьте доставку настоящего тестового письма в свою почту. Включите ограничение частоты запросов в Vercel Firewall: honeypot и проверка Origin отсеивают часть нежелательных запросов, но не заменяют защиту от ботов. Уточните информационный текст о данных клиентов для реальной работы мастерской — текущий блок описывает передачу заявки, но не является полной политикой обработки данных.

**Бесплатность:** Vercel Hobby предназначен для личного некоммерческого использования. Для сайта, принимающего платные заказы, не рассчитывайте на Hobby: выберите тариф, разрешающий коммерческое использование. Домен оплачивается отдельно, если его ещё нет. У Resend есть бесплатная квота; актуальные лимиты смотрите в своём аккаунте. Источники и подробности — в гайдах.
